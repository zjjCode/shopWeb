## 三、进度更新约定（团队铁律）

1. **每完成一个任务**：工程师/QA 立即把本表对应行改为 ✅ 并填写更新时间，同时把「当前状态」的指针前移。
2. **开始一个任务前**：先把状态改为 🔵 进行中，避免两人同时认领。
3. **遇到阻塞**：改为 ⛔ 并在 `docs/07-开发流程记录.md` 记录阻塞原因与解决思路，不要静默跳过。
4. **代码与文档同步**：任何模块实现完成，必须同步更新本文档任务表 + 流程记录日志；接口变更必须同步 `docs/09-使用文档.md`。
5. **中断恢复**：新会话开始时先读「当前状态」小节与 `docs/07-开发流程记录.md` 最近 3 条记录，即可无缝接续。
